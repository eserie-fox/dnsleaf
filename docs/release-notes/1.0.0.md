# Release Notes: 1.0.0

Release date: 2026-04-01

## Highlights

- workspace-centric runtime configuration is now the clear operator-facing model
- outside-workspace defaults are explicitly internal fallback behavior for commands that run before a workspace exists
- arbor-ddns logging uses one shared schema across workspace and outside-workspace contexts
- discovery path defaults and workspace runtime paths have clearer layered ownership
- scaffold default construction is concentrated in typed model/config helpers instead of storage
- compatibility leftovers were cleaned up and release metadata is aligned for local installation

## Operational model

`workspace.yaml` remains the source of truth for normal operation:

- Cloudflare zone and token settings
- discovery and systemd execution paths
- workspace-local arbor-ddns logging
- apply, render, plan, sync, and uninstall behavior

Outside a workspace, arbor-ddns uses its packaged internal defaults only for fallback discovery commands and bootstrap stderr logging.

## Packaging and verification

This release aligns the local-install workflow around:

```bash
uv sync --extra dev --python 3.11
.venv/bin/python -m build
pip install dist/arbor_ddns-1.0.0-py3-none-any.whl
arbor-ddns --version
```
