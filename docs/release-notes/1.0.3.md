# Release Notes: 1.0.3

Release date: 2026-04-02

## Highlights

- `entry update` can now explicitly clear an entry-level `proxied` override and return to inheriting the workspace default
- `entry` proxied flags are now aligned around explicit `--proxied/--no-proxied` behavior instead of leaving update as a one-way flag
- docs, tests, release notes, and version metadata are aligned for the 1.0.3 patch release

## Operational notes

This is a patch release that keeps the current workspace and Cloudflare sync model intact:

- `workspace.yaml.default_proxied: null` remains the scaffold default
- planner and provider semantics for unmanaged proxy state are unchanged
- `entry update --inherit-proxied` removes the entry-level override, so the entry goes back to inheriting the workspace default

## Packaging and verification

This release keeps the same local-install workflow, with versioned artifacts updated to 1.0.3:

```bash
pip install -e '.[dev]'
python -m build
pip install dist/arbor_ddns-1.0.3-py3-none-any.whl

```
