# Release Notes: 1.0.2

Release date: 2026-04-01

## Highlights

- `local` is now a first-class dynamic source kind for discovering IP candidates from the machine running arbor-ddns
- low-level discovery, workspace entries, sync orchestration, and privilege analysis all recognize the new local-host dynamic flow
- workspace file logging now preserves the configured stable `arbor-ddns.log` symlink path instead of appending repeated date suffixes to dated log files
- help text, operator docs, changelog, release notes, and version metadata are aligned for the 1.0.2 patch release

## Operational notes

This is a patch release that keeps the existing workspace and config model intact:

- workspace schema and command names are unchanged
- `local` remains a dynamic discovery source and still flows through the existing discovery and selection pipeline
- static entries remain explicit-value only
- workspace daily logging still uses one stable symlink plus dated files, but repeated date suffixes are no longer generated

## Packaging and verification

This remains an internal/local build-and-install workflow. It does not add a PyPI publishing path.

Versioned artifacts for this release are:

```bash
pip install -e '.[dev]'
python -m build
pip install dist/arbor_ddns-1.0.2-py3-none-any.whl
arbor-ddns --version
```

See [Internal Release Workflow](../release.md) for the full local build and smoke-test sequence.
